timeline

2025–2026

These years have been defined by my work as a Software Engineer at Anaplan. I develop production software using Python, TypeScript and React while maintaining Kubernetes deployments, Jenkins CI/CD pipelines and AWS infrastructure. A large part of my focus has been AI agent capabilities for Anaplan model building: I design and implement TypeScript MCP tools that read model structure and create or update modules, lists, line items and formulas. Those tools sit on top of the existing Weaviate RAG pipeline so the agent can retrieve model context and then apply changes through MCP. I also design Grafana dashboards for traces, logs and metrics, and take part in production incident response across distributed services.

2023

This year marked the beginning of my journey as a software engineer at Fishbone Solutions in Derby. One of my key achievements was spearheading the development of the company's inaugural commercial application—an Engineering Change system, replacing the outdated EMR (East Midlands Railway) system for our client. The positive feedback received from EMR opened doors to new opportunities for our software team. Leveraging a full-stack approach, I utilized cutting-edge technologies such as React, Redux, and Bootstrap for the frontend, while employing Node.js, PostgreSQL, and Prisma ORM for robust backend functionality. Additionally, I implemented Auth0 for seamless authentication across the company's systems, extending its benefits beyond the EMR application to any other cloud-deployed applications within the company's ecosystem. The success of this project fuels my enthusiasm to further enhance my skills; I've begun immersing myself in TypeScript to bolster application reliability. Concurrently, I've embarked on exploring application development in the .NET core, discovering its rich array of services and features that empower developers like never before.
